## 📌 About the Project

This project focuses on writing clean, semantic, and accessible HTML markup without external styling. It demonstrates the structural foundation of a modern web page, including content grouping, forms, media handling, and accessibility attributes.

## 🛠️ Key HTML Concepts Practiced

* **Semantic Layout Elements:** Using `<main>`, `<section>`, `<figure>`, `<figcaption>`, and `<footer>` rather than generic `<div>` wrappers.
* **Forms & User Inputs:** Radio buttons (`type="radio"`), checkboxes (`type="checkbox"`), required text inputs (`required`), and grouped options with `<fieldset>` and `<legend>`.
* **Media & Accessibility:** Embedding external images with descriptive `alt` tags and clickable anchor (`<a>`) wrappers.
* **Lists:** Structuring ordered (`<ol>`) and unordered (`<ul>`) lists.
